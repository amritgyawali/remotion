# Original visual production kit

This folder contains editable SVG objects, icons, arrows, neon graphics,
geometry, and browser-safe 3D/depth artwork generated by
`scripts/generate-visual-assets.mjs`.

- Use a file in Remotion with `<Img src="/assets/visual/v1/objects/phone.svg" />`.
- Browse exact file paths in `v1/catalog.json`.
- All assets are original geometric constructions and released under CC0-1.0.
- SVG source stays editable: change strokes, fills, opacity, or paths freely.

The AI Master Template also embeds a compact procedural version of this kit so
its download → AI edit → single-file re-upload workflow remains self-contained.
