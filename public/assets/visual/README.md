# Original visual production kit

This folder contains 1,241 editable, deterministic SVG files generated by
`scripts/generate-visual-assets.mjs`: 41 stable legacy assets and 1,200 new
procedural visuals. No downloaded artwork or third-party icon paths are used.

The procedural library has 24 addressable families across `kinetic`, `organic`,
`cosmic`, `frames`, `data`, and `symbols`. Every family has 50 variants:

```tsx
staticFile('assets/visual/v1/kinetic/burst-001.svg')
staticFile('assets/visual/v1/data/network-050.svg')
```

`v1/catalog.json` records each file's family, style, deterministic seed,
recommended roles, prohibited roles, byte size, geometry fingerprint, and
SHA-256 checksum. Its compact top-level `families` index provides the exact path
prefix and variant range for deterministic selection.

The 41 legacy paths remain stable. `geometry/grid.svg` is retained only for
backward compatibility: its catalog entry has `generationEligible: false` and
`prohibitedRoles: ["background"]`.

- SVG source stays editable: change paths, strokes, fills, and opacity freely.
- Generated artwork is released under CC0-1.0.
- Regenerate with `npm run assets:visual`.
- Verify files, catalog integrity, duplicates, missing files, and orphans with
  `node scripts/generate-visual-assets.mjs --verify-only`.
