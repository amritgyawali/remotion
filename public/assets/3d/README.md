# Original 3D production kit

This folder contains 1,200 deterministic glTF Binary 2.0 (`.glb`) models and
1,200 matching SVG previews generated by `scripts/generate-3d-assets.mjs`. Every
mesh is built from project-owned geometry recipes: no downloaded models, scanned
meshes, or third-party asset-store content.

Unlike the other asset families, **the generated pack is not committed**. It is
about 31 MB of binaries that only the Remotion 3D samples read, and it rebuilds
byte-for-byte from the seed, so `public/assets/3d/v1/` is ignored by git and
regenerated in CI instead. This README and `LICENSE-3D.md` are the only tracked
files here. Run `npm run assets:3d` once after cloning if you want to work with
the samples locally.

The library has 24 addressable families across eight categories - `characters`,
`objects`, `icons-3d`, `items`, `vehicles`, `architecture`, `nature`, and
`abstract-motion` - three families per category. Every family has 50 variants:

```tsx
staticFile('assets/3d/v1/characters/hero-bot/hero-bot-001.glb')
staticFile('assets/3d/v1/abstract/geometric/orbital-torus.glb')
```

`v1/catalog.json` records each model's category, family, variant, deterministic
seed, style, tags, recommended roles, triangle/node/material counts, bounding
box, byte size, geometry fingerprint, and SHA-256 checksum - plus the same for
its preview. Its top-level `categories` and `families` indexes give the exact
path prefix and variant range for deterministic selection.

Models are low-poly and self-contained: PBR materials are embedded, the axis
convention is Y-up, and nothing references an external texture or buffer file.
The full pack is 24.82 MiB across 377,134 triangles.

- Generated geometry is released under CC0-1.0.
- Regenerate with `npm run assets:3d`.
- Verify files, catalog integrity, duplicates, missing files, and orphans with
  `node scripts/generate-3d-assets.mjs --verify-only`.
